
# Verified Roadmap resources

The Roadmap will use official, learner-oriented resources and show a verification date in the UI.

| Topic | Resource | URL | Verification note |
|---|---|---|---|
| Web APIs | MDN, “Introduction to web APIs” | https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Client-side_APIs/Introduction | Explains APIs as abstractions and distinguishes browser APIs from third-party APIs; retrieved 2026-08-28. |
| HTTP | MDN, “Overview of HTTP” | https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview | Official MDN guide selected for request/response fundamentals; discovered in current search results. |
| Git | Pro Git, “Getting Started” | https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control | Official Pro Git book provides beginner chapters on version control, Git basics, remotes, and branching; retrieved 2026-08-28. |
| Python | Python Tutorial | https://docs.python.org/3/tutorial/index.html | Official Python tutorial selected for beginner language foundations; discovered in current search results. |
| GitHub REST | GitHub Docs, “Getting started with the REST API” | https://docs.github.com/rest/using-the-rest-api/getting-started-with-the-rest-api | Official GitHub documentation selected for practical API requests; discovered in current search results. |

The app should keep the source links as external links with `target="_blank"` and `rel="noreferrer"`, and should not claim that a resource was personalized unless the profile/mission data explains the reason.
